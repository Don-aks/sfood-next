We use Next.js for frontend and backend development, TypeScript as our primary programming language, Tailwind CSS for styling, Supabase for database management and authentication, and Redux Toolkit for state management.

### Why?

- **Next.js** provides frontend and backend capabilities within a single project. It simplifies the overall application architecture and offers features such as Server-Side Rendering (SSR), which can improve SEO and initial page loading performance.

- **TypeScript** is widely used in modern web development because it provides static typing, helps catch errors during development, and improves code readability and maintainability.

- **Tailwind CSS** speeds up development and helps maintain a consistent design system through its utility-first approach. It also integrates well with **shadcn/ui**, making it easier to build customizable UI components.

- **Supabase** provides a PostgreSQL database, authentication, and backend services out of the box. It allows us to focus on application logic instead of building these features from scratch.

- **Redux Toolkit** simplifies global state management and provides a predictable way to manage application data. We use it to manage the shopping cart and persist its state between page reloads.

## Workflow

We use GitHub Projects to organize tasks and track development progress. We manage tasks through GitHub Issues, organize them into Milestones, and use Pull Requests to review and merge changes.

## Features

- **Authentication** — user registration and login.
- **Shopping Cart** — adding, removing, and updating products in the cart.
- **Order Placement** — creating and submitting orders.
- **Payments** — Stripe integration for secure payment processing.

## Dev Notes

We started this project without a clear plan, believing we could finish it quickly. However, reality turned out to be different. We realized that we needed to plan the development process and design the application in Figma before choosing the right technology stack.

This experience taught us that proper planning and design are important parts of web development process, not just steps we can skip to start coding faster.
