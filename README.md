## Stack

![NextJS Logo](https://img.shields.io/depfu/dependencies/github/don-aks%2Fsfood-next?logo=nextdotjs)

We use Next.js for SSR and backend, TypeScript as main language, Tailwind for styles, Supabase as data base managment and Redux RKT as state manager.

### Why?

- Next.js provides backend and frontend in one repository. It simplify architecture of whole application. Also that framework offers Server Side Rendering, which helps in SEO and TTFB metrics.
